# Python - Test-driven development

Writing tests first: doctests (in `tests/*.txt`) and `unittest` test cases, with functions that validate their arguments and raise the right exceptions.

| File | Description |
| ---- | ----------- |
| `0-add_integer.py` | `add_integer(a, b=98)` adds two integers or floats, as integers |
| `2-matrix_divided.py` | `matrix_divided(matrix, div)` divides all elements of a matrix, rounded to 2 decimals |
| `3-say_my_name.py` | `say_my_name(first_name, last_name="")` prints `My name is <first name> <last name>` |
| `4-print_square.py` | `print_square(size)` prints a square with the character `#` |
| `5-text_indentation.py` | `text_indentation(text)` prints a text with 2 new lines after each `.`, `?` and `:` |
| `6-max_integer.py` | `max_integer(list=[])` returns the max integer of a list (given) |
| `100-matrix_mul.py` | `matrix_mul(m_a, m_b)` multiplies two matrices |
| `tests/0-add_integer.txt` | Doctests for `add_integer` |
| `tests/2-matrix_divided.txt` | Doctests for `matrix_divided` |
| `tests/3-say_my_name.txt` | Doctests for `say_my_name` |
| `tests/4-print_square.txt` | Doctests for `print_square` |
| `tests/5-text_indentation.txt` | Doctests for `text_indentation` |
| `tests/6-max_integer_test.py` | Unittests for `max_integer` |
| `tests/100-matrix_mul.txt` | Doctests for `matrix_mul` |
