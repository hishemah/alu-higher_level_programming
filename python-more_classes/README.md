# Python - More Classes and Objects

A `Rectangle` class built up step by step: properties, `__str__`, `__repr__`, `__del__`, class attributes, a static method and a class method.

| File | Description |
| ---- | ----------- |
| `0-rectangle.py` | An empty class `Rectangle` |
| `1-rectangle.py` | Private `width` and `height` with validating properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | `print()` and `str()` draw the rectangle with `#` |
| `4-rectangle.py` | `repr()` returns a string that `eval()` can turn back into a rectangle |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Counts instances in the class attribute `number_of_instances` |
| `7-rectangle.py` | Draws with the class attribute `print_symbol`, which can be any type |
| `8-rectangle.py` | Static method `bigger_or_equal()` returns the rectangle with the bigger area |
| `9-rectangle.py` | Class method `square()` returns a new rectangle with equal sides |
