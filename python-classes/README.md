# Python - Classes and Objects

A `Square` class built up step by step: private attributes, validation, properties and printing.

| File | Description |
| ---- | ----------- |
| `0-square.py` | An empty class `Square` |
| `1-square.py` | `Square` with a private instance attribute `size` |
| `2-square.py` | `Square` whose `size` must be an integer `>= 0` |
| `3-square.py` | Adds the public method `area()` |
| `4-square.py` | Adds a `size` property with a validating setter |
| `5-square.py` | Adds `my_print()`, which prints the square with `#` |
| `6-square.py` | Adds a validated `position` property used by `my_print()` |
