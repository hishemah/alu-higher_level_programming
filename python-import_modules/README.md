# Python - import & modules

Programs that import functions and variables from other modules, read command-line arguments and guard their code with `if __name__ == "__main__":`.

| File | Description |
| ---- | ----------- |
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `1-calculation.py` | Imports `add`, `sub`, `mul` and `div` from `calculator_1.py` and prints their results for 10 and 5 |
| `2-args.py` | Prints the number of arguments and the list of arguments |
| `3-infinite_add.py` | Prints the sum of all arguments |
| `4-hidden_discovery.py` | Prints the names defined by the compiled module `hidden_4.pyc`, except those starting with `__` |
| `5-variable_load.py` | Imports the variable `a` from `variable_load_5.py` and prints its value |
