# Python - Network #0

HTTP basics with `curl`: request methods, headers, status codes, redirects and request bodies, plus a peak-finding algorithm.

| File | Description |
| ---- | ----------- |
| `0-body_size.sh` | Displays the size in bytes of the body of the response |
| `1-body.sh` | Displays the body of a 200 status code response to a GET request |
| `2-delete.sh` | Sends a `DELETE` request and displays the body of the response |
| `3-methods.sh` | Displays all the HTTP methods the server accepts |
| `4-header.sh` | Sends a GET request with the header `X-HolbertonSchool-User-Id: 98` |
| `5-post_params.sh` | Sends a POST request with the variables `email` and `subject` |
| `6-peak.py` | `find_peak(list_of_integers)` finds a peak in a list of unsorted integers |
| `6-peak.txt` | Complexity of `6-peak.py`: O(log(n)) |
| `100-status_code.sh` | Displays only the status code of the response |
| `101-post_json.sh` | Sends a JSON POST request with the contents of a file |
| `102-catch_me.sh` | Makes `0.0.0.0:5000/catch_me` answer `You got me!` |
