# Python - Hello, World

First steps with Python 3: running scripts, `print`, f-strings, string slicing and concatenation.

| File | Description |
| ---- | ----------- |
| `0-run` | Shell script that runs the Python file stored in `$PYFILE` |
| `1-run_inline` | Shell script that runs the Python code stored in `$PYCODE` |
| `2-print.py` | Prints `"Programming is like building a multilingual puzzle` |
| `3-print_number.py` | Prints the integer in `number` followed by `Battery street` using an f-string |
| `4-print_float.py` | Prints the float in `number` with 2 digits of precision |
| `5-print_string.py` | Prints a string 3 times, then its first 9 characters |
| `6-concat.py` | Prints `Welcome to Holberton School!` using `str1` and `str2` |
| `7-edges.py` | Prints the first 3 letters, last 2 letters and middle of a word |
| `8-concat_edges.py` | Builds `object-oriented programming with Python` by slicing an existing string |
| `9-easter_egg.py` | Prints The Zen of Python |
