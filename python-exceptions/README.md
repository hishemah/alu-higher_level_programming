# Python - Exceptions

Functions that handle errors with `try`, `except`, `finally` and raise exceptions.

| File | Description |
| ---- | ----------- |
| `0-safe_print_list.py` | Prints up to `x` elements of a list and returns how many were printed |
| `1-safe_print_integer.py` | Prints a value as an integer, returning `True` on success and `False` otherwise |
| `2-safe_print_list_integers.py` | Prints only the integers among the first `x` elements of a list |
| `3-safe_print_division.py` | Divides two integers and prints the result in a `finally` block |
| `4-list_division.py` | Divides two lists element by element, handling wrong types, division by 0 and out of range |
| `5-raise_exception.py` | Raises a `TypeError` |
| `6-raise_exception_msg.py` | Raises a `NameError` with a message |
